A travel poster for VELMARA, a terraced harbour town that does not exist: golden-hour light over a teal bay, a spiral lighthouse on the rocky point, sailboats, and the town's name set in large serif capitals. The artwork is an original programmatic illustration rendered with PIL (`render.py`); `main.ts` copies the committed `entry.png` (1024×1024) to `/output/entry.png`.
